**Organization:** New Light Technologies  
**My role:** Web developer

I developed an interactive web map using internal data from the US Virgin Islands Department of GIS. The application brought together address locations, estates, historic districts, and other geographic information in a browser-based interface. The application supported field personnel in confirming addresses associated with access to government services. The project connected a practical addressing need with a web-development approach that made the information available through an interactive map.

Using JavaScript, HTML, Leaflet, and ArcGIS REST services, I connected existing GIS resources to an interactive map. My work focused on integrating those layers and presenting them together so users could examine individual locations within their surrounding geographic context.

For example, displaying address locations alongside estate and historic-district information allowed those datasets to be viewed together. The application provided a practical way to explore information already maintained by the department.

Using open-source front-end tools helped reduce reliance on the previously licensed mapping software. The value of that approach was in making better use of existing spatial services and providing an easy and longlasting way for staff to access them.
